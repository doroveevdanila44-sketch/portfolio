# Портфолио цифровых решений

Одна страница: Beauty Box Eco, KamBarShop, налоговый агент и «Луна» (ES Fitness CRM). Все проекты и скриншоты отображаются сразу, без вкладок и галерей.

## Запуск и Vercel

Статический сайт без сборки и зависимостей. Раздавайте каталог `dist` любым HTTP-сервером. На Vercel выберите Framework Preset: Other, пустой Build Command и Output Directory: `dist`.

## Файлы

`dist/index.html` — содержание, `dist/styles.css` — оформление и адаптивность. Скриншоты находятся в `dist/assets`.

Время 11:20 и системные значки показаны поверх исходных мобильных скриншотов средствами HTML/CSS. Dynamic Island скрыт этой же системной панелью. Исходные изображения сохранены без перерисовки интерфейсов.
